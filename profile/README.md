## What Alessja is

A pocket companion that runs entirely on your phone. No cloud, no telemetry, no rate-limit on chat.

- **Free-tier chat: unlimited, forever, offline.** No daily cap, no message quota.
- **Premium adds features, not chat volume** — themes, conversation history, file upload, export.
- **Apache 2.0 model basis** (Qwen 3.5-2B/4B via llama.rn).
- **DSGVO-by-architecture** — your data never leaves the device.

## Stack

| Layer | Tech |
|---|---|
| App | Expo SDK 54 · React Native · TypeScript strict |
| LLM | Qwen 3.5-4B Q4_K_M (flagship ≥6 GB RAM) / 2B v2 (entry) via `llama.rn`, GGUF on EU R2 CDN |
| Voice (WIP) | Piper VITS resume-training toward epoch 5000 |
| Storage | AsyncStorage — 100% local persistence, no backend DB |
| Notifications | expo-notifications + notifee dual stack |
| Themes | 6 themes incl. premium animated video backgrounds |
